# 第三部分问答操作清单

本清单是操作教程，不是已完成实验记录。第三部分与第四部分分别执行、分别评价。

## 1. 准备同一组问题

自行选择至少四题：两道时效性/冷门事实题、一道常识题、一道经过独立核验的陷阱题。三版使用完全相同的问题文字和顺序，不把参考答案或纠正提示加入问题。不需要修改 evaluate.py。

可以沿用已讨论的医疗四题，也可以换成其他符合要求的题目；“今年”应记录实际实验日期。实验前完成陷阱前提核验，实验后独立核验事实回答。

## 2. 每版启动一次，连续问四题

在项目根目录 PowerShell 执行：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\run_demo.py --version V1
```

出现“问题>”后逐题输入。每题回答完先截图，再输入下一题；四题完成输入 quit。分别把 V1 改成 V2、V3 重复同一组问题。

默认连续提问，每题独立作答，没有跨题记忆。使用 `--question "完整问题"` 时只问这一题并退出。盲答演示使用 `--version blind`，问题本身无需加“盲答”。

## 3. 会话与截图

- `outputs/sessions/`：每次启动首次提问时创建一份 JSON，名称为“版本_session_会话第一道问题.json”，后续问答追加至同一文件。非法字符替换、长问题截断、同名加序号；完整问题保留在记录中。
- `outputs/screenshots/`：自行截图，程序不往这里写日志。建议命名 V1_Q1.png 至 V3_Q4.png。
- JSON 保存实际提示词、模型、问题、回答和成功返回的搜索日志；失败或中断记录异常类型。旧会话如缺少新增字段，不能事后推定当时提示词。

截图包含版本、完整问题、实际搜索关键词（如有）、Token 和最终回答；长输出可分图并保留重叠。日志不能替代截图。每题全部 Token 行需累计，不能只记录最后一次。

## 4. 人工比较

按真实问答填写 [第三部分对比表模板.csv](第三部分对比表模板.csv)。复制到 `outputs/sessions/第三部分对比表.csv` 后填写，每版每题一行；模板只有表头，不预设题目或评价。

记录类型、搜索次数与关键词、关键词合理性、答案正确性、角色风格、是否编造、独立核验来源、截图文件以及会话文件和 turn 序号。不知道不自动算事实题正确，无结果不自动等于关键词不合理。V1 没有医疗角色要求，V2/V3 按医疗角色及能力边界评价。

保留错误、拒答、空检索和失败，不反复重问以挑选好答案。最终仍为“搜索:”时记为未完成，不能当作答案。

## 5. 环境演示与第四部分

课程环境跑通另需 RAG 与盲答各至少一次真实演示；可复用符合要求的截图，也可单独运行。第三部分至少 12 个问答任务，第四部分固定 60 个任务；RAG 任务数不等于模型调用次数。

第四部分：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\evaluate.py --workers 3 --output-dir outputs/experiment_search_fixed
& 'E:\Professional\py\python.exe' -X utf8 scripts\export_experiment_summary.py --input-dir outputs/experiment_search_fixed
```

当前命令的数据与统计仅写 `outputs/experiment_search_fixed/`，不读取第三部分会话、不预设第三部分题目。已有缓存只补缺失任务，失败不自动重试；模型、提示词、数据或样本不一致时停止续跑。重测指定 `--output-dir outputs/experiment_v2`，统计指定 `--input-dir outputs/experiment_v2`，保留原版本。

统计生成 accuracy.png、token_comparison.csv、summary.json、实验结果摘要.md。前五题输入 Token 来自固定测试集，按全部模型调用累计；另写 2～3 句真实分析，不把空搜索说成有效网页证据。

第三部分使用自选同题与真实会话，已移除停用的固定四题清单和旧空模板。


接口检查、失败记录、搜索修复、未知 Token 处理与测试结论统一见 [项目检查与修复记录](项目检查与修复记录.md)。修复前 outputs/experiment/ 保留，修复后实验另存 outputs/experiment_search_fixed/，不能混用成绩。

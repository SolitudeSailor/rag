# 第四部分评价标准

依据《RAG项目目标.md》第四部分，正式结果采用课程字符串包含评分。

- 数据：指定NQ-open开发集3610题，seed=42固定抽样30题。
- 任务：同30题分别盲答和V3 RAG，共60项；只把问题传给模型，不传标准答案。
- 判分：`any(ans.lower() in response.lower() for ans in answers)`。两种模式完全一致，不进行同义词、标点或词边界替换。多候选回答只要命中也判对，这是课程规则的局限。
- 异常或未完成的搜索指令不是最终回答，计错；失败保留在30题分母，缺失任务拒绝统计。合法最终回答即使含额外错误信息，只要命中仍按课程判对。
- 准确率：正确题数/30×100%；增益为同轮RAG准确率减盲答准确率。多对2题满足≥5个百分点，多对3题满足≥10个百分点的准确率条件；优秀还需图表和结果分析。
- 正式`results.csv`恰好六列：question、gold_answers、blind_answer、rag_answer、blind_correct、rag_correct。状态、搜索数和Token另存`task_details.csv`；逐次usage继续保留在原始JSON。
- Token按每题所有调用累计，任何一次usage缺失则累计标为未知，不以部分用量充当完整用量。
- 调优轮次全部报告；不跨轮拼接盲答、不挑选逐题输出，不把固定集调优称为独立泛化测试。人工事实核验可另作补充，不能替换课程评分。

`evaluation_standard.py`为评测和导出共用的判分来源。已有七轮已离线重算到`outputs/experiment/standardized_20261011/`，保留历史文件；重算未新增模型调用，成绩没有改变。第2轮单轮达标，七轮只有一轮达标，不能证明稳定提升。

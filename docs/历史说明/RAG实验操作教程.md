# RAG 实验操作教程（重新开始）

逐题命令、两种模式的输入区别、问答次数及日志保存步骤见 [问答操作清单](问答操作清单.md)。

本项目已存在数据集实验结果，当前摘要为盲答 17/30、V3 RAG 15/30，19 次搜索均为空摘要。以下是操作步骤，不能当作新实验完成记录。用户自行问答、截图和人工核验；助手当前不操作桌面。

## 1. 环境确认

在项目根目录打开 PowerShell：

```powershell
Set-Location 'C:\Users\SolitudeSailor\Desktop\rag'
chcp 65001
.\.venv\Scripts\python.exe -X utf8 search_rag_example.py
```

复用现有 `.env` 和 `.venv`，无需重新输入密钥或安装依赖。不要展示 `.env`。仅在没有现成环境的新电脑上，参考根目录依赖清单安装。

先分别提一个 RAG 问题和一个 `盲答 问题`，保留真实输出；输入 `quit` 退出。时效性问题应展示实际搜索词与最终回答，若没有搜索，如实记录并另做工具调用演示。

## 2. 三版同题测试

核心文件只允许修改 V2/V3 提示词，V2/V3 始终保持医疗助手身份。默认 V3 保留；用实验入口选择版本，不必更改核心函数：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\run_demo.py --version V1
```

在 `问题>` 后输入题目，等 `[最终回答]` 出现再截图。默认可以连续问四题，输入 quit 退出后再分别启动 V2、V3。也可以用 `--question "完整问题"` 直接提供题目。

以下四题仅为第三部分参考题；可以自行选题，但三版必须使用同一组、完全相同文字，不需要修改第四部分脚本：

| 编号 | 类型 | 完整问题 |
|---|---|---|
| Q1 | 时效事实 | 2026年诺贝尔物理学奖获奖者是谁？ |
| Q2 | 冷门参数 | STM32F103C8T6 的 Flash 容量是多少 KB？ |
| Q3 | 常识计算 | 计算 12×8 并说明计算过程。 |
| Q4 | 待核验的虚假前提 | J.K.罗琳已经出版的《哈利波特》第九部小说叫什么？请概述剧情。 |

这是重启前保留的题目设计，不沿用旧参考答案。新实验前，应使用诺贝尔奖官方公告、ST 官方型号资料、作者或出版社官方目录独立核验。Q4 必须先确认其前提确实虚假；若不满足要求，应在运行前统一替换三版手工题目。记录核验日期与链接，不把标准答案加入模型问题。计算题 12×8=96。

示例命令：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\run_demo.py --version V1 --question "2026年诺贝尔物理学奖获奖者是谁？"
```

每版重复四题，共 12 次，保留错误、拒答及无搜索现象，不能只挑选成功输出。未完成的 `搜索:` 指令不能当作最终回答。

## 3. 保存截图与手工记录

1. 最大化终端，保证版本、完整问题、真实搜索过程、Token 和最终回答清晰可见。
2. 使用 `Win+Shift+S` 截取真实终端，存入 `outputs/screenshots/`，命名 `V1_Q1.png` 等。
3. 长输出可分成过程与回答两张，保留重叠文字；不得用排版日志或模拟图替代截图。
4. 题目结束后再清屏，截图避开密钥和无关敏感内容。

问答脚本将本次会话的全部记录保存到 `outputs/sessions/` 中独立命名的 JSON，每题完成立即更新；`outputs/screenshots/` 仅供手工存放截图。

手工表模板见 [第三部分对比表模板.csv](第三部分对比表模板.csv)，复制到 outputs/sessions/ 后填写。手工表需要记录：版本、题号、类型、完整问题、实际搜索次数及关键词、关键词合理性、答案正确性、角色风格、是否编造、完整回答、独立核验来源和截图文件。无搜索写“未搜索”；事实正确与遵守搜索规则分别判断；“不知道”不能自动算事实题正确。

## 4. 固定 30 题评测

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\evaluate.py --workers 3 --output-dir outputs/experiment_search_fixed
```

运行前确认提示词副本与核心 V3 一致。官方数据缓存位于 `data/NQ-open.dev.jsonl`，缺失时自动下载。固定 `random.seed(42)`，同一组 30 题分别真实调用盲答和 RAG，只执行第四部分的 60 个任务，不运行三版四题。

当前命令输出位于 `outputs/experiment_search_fixed/`；修复前 `outputs/experiment/` 保留：

| 文件 | 内容 |
|---|---|
| `sample30.json` | 固定题目、原始索引和标准答案 |
| `metadata.json` | 模型、配置、抽样和源码/提示词/数据集哈希 |
| `prompts.json` | 实际三版提示词 |
| `raw_results.json` | 完整回答、搜索摘要、状态和逐次 usage |
| `results.csv` | 规定六列及状态、搜索次数、输入 Token |

评分采用课程要求的大小写归一后字符串包含规则，失败题仍留在分母。标准答案仅用于评分，不输入模型。不能换样本、删除失败题或挑选成功输出来提高分数。

中断后原命令会继续尚未完成任务。改提示词或模型后，用 `--output-dir outputs/experiment_v2` 指定新目录，统计时对应指定 `--input-dir outputs/experiment_v2`；脚本会阻止配置不一致的缓存续跑，保留完整版本证据。若在固定 30 题上调优，报告须注明这不是独立泛化测试。

## 5. 图表、Token 与报告

批量实验完成后，用本机已有 Pillow 的解释器离线整理：

```powershell
& 'E:\Professional\py\python.exe' -X utf8 scripts\export_experiment_summary.py --input-dir outputs/experiment_search_fixed
```

生成准确率柱状图、前五道固定样本的输入 Token 对比、第四部分摘要。第三部分依据 sessions/ 会话单独填写三版对比表、保存真实截图并完成人工评价；统计脚本不读取会话，也不预设第三部分题目。RAG 每题输入 Token 应累计全部调用，逐次 usage 保留在原始 JSON。

Token 分析写 2～3 句，结合实际搜索次数、检索摘要长度、累计调用和准确率，不能只用最后一次调用数值比较。

后续新 Word 存入 `reports/`，依照根目录 `RAG项目目标.md`，沿用“一、项目目的”至“七、提交要求”的章节和小题名称。理论 12 小题每题 100～200 字，公式使用规范数学表达。封面和小组分工放正文前；三人信息与真实分工待补，每人总结不少于 200 字，不能代编经历。

目前没有新报告，也没有适用于新一轮的自动报告生成器。旧报告生成及修订脚本已退出活动目录。后续先取得真实实验材料再生成可编辑 Word，检查公式、表格、图片清晰度和分页；暂不生成 PDF。

# 开发记录

合并原来的六份历史说明，保留问题与修复，重复操作统一见[实验指南](../实验指南.md)。旧成绩与旧目录不作为当前依据，现行架构见[项目索引](../../索引%20index.md)。

## 环境与接口

- 问答和绘图曾使用不同Python环境，Pillow缺失导致导出无法执行；统一入口现补齐依赖，所有任务使用项目`.venv`。
- 配置使用`.env`，环境变量优先；改配置需重启进程。凭据不硬编码或输出。
- Windows终端及临时启动器曾有中文编码和模块路径问题，现统一UTF-8与项目定位。
- 沙箱内模型、搜索连接失败，沙箱外可正常访问；不能据沙箱内认证检查断言凭据失效。
- 历史一轮出现大量API状态错误，后续HTTP 402带余额／额度信号；该轮不用于判断正常服务效果。

## 检索与模型

- 旧`cn.bing.com/search`返回301后跳首页，摘要为空；改用`www.bing.com/search`后可返回摘要。
- 非空摘要仍可能无关：节目名返回冠词释义、电影名返回缩写、歌曲名返回字母解释。完整查询与实体相关性成为主要瓶颈。
- 后续增加请求与返回查询检查、验证页识别、来源链接和相关性筛选。
- 2026-10-14先接入百度百科，随后按授权换为中英文维基百科官方API；旧实现保留于`outputs/retrieval_versions/`。
- 再补充年度表格、跨行年份、实际权威引用正文、辅助Bing、系统时钟和Open-Meteo天气。详见[检索代码说明](../检索代码说明.md)。
- 模型仍可能认错实体、擅自补年份、英文题中文答、输出过长或描述不存在的搜索次数。
- V1保留教师版，V2/V3保持医疗角色与能力边界，V3含完整模拟Few-shot。拒答可减少无依据输出，但不能补足检索；模拟示例不是实际查询证据。

## 评分、Token与保存

- 历史文件曾混有演示与额外任务，共72项；现第三部分独立记录，正式评测固定30题两模式共60项，标准答案不传模型。
- 评分曾分散、CSV包含额外列；现共用`experiment_utils.py`，六列CSV与任务详情分开。
- 字符串包含会漏判同义表达，也可能给夹杂错误但包含标准答案的回答得分；人工核验只能另作补充。
- `usage`及字段可能缺失；现兼容并标未知，每题累计所有调用，不将部分或最后一次用量当完整值。
- 增加逐次搜索检查点、失败状态和并发日志隔离，避免中断丢失过程。
- 新实验自动编号，续跑校验模型、接口、提示词、源码、检索配置及样本；只补缺失，失败不自动重试。
- 提示词与检索实现分版本保存；导出核验原始回答、判分、CSV与累计Token一致性。

# 检索修复方案（待授权，尚未实施）

当前仅允许修改核心V2/V3提示词。第8轮提示词调优使RAG降至12/30，未采用；此前最高绝对准确率21/30的一轮也未满足同轮提升5个百分点。不能保证下面的修复一定达到优秀线。

已观察的问题：Bing返回HTTP成功和非空摘要，但内容常与实体无关。例如节目嘉宾查询取得冠词定义，电影配音查询取得TAD缩写相关页面；四条中文查询探针也全部不相关。问题根因尚未确定，不把非空摘要视为检索成功。

拟修改范围仅为`search_rag_example.py`的`bing_search()`及必要的检索辅助函数：

1. 保存请求查询、实际返回查询与页面类型的诊断证据，识别重定向、验证页、页面查询不一致及异常缓存，先解决查询传输问题。诊断不记录密钥或环境变量。
2. 检索结果带标题、来源URL和摘要；增加实体与查询相关性检查，明显无关的结果不注入模型。空结果继续如实返回，不伪造证据。
3. 若现有入口确实无法恢复，再比较可用备用检索来源；只在真实查询验证相关性后接入，避免未经验证的百科原型直接替换搜索。
4. 使用现有环境和依赖，不更改模型、温度、盲答、固定样本或课程评分。检索配置和源码另存版本，旧实验不覆盖。

验证：先以非标准答案查询核验页面与查询一致、相关结果和来源；通过后再完整执行固定30题两模式60任务。失败保留，报告同轮差值，不跨轮拼接，不挑选逐题答案。只有真实结果达到条件才称达标；固定集调优仍不代表独立泛化测试。

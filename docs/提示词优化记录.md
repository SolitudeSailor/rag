# 当前提示词优化记录

2026-10-15 更新 V2/V3，版本标记为 `search-precision-prompt-v1`。目标是改善关键词生成、证据核对和第二轮搜索的使用方式，而非依靠扩写答案命中标准答案。

## 主要调整

| 原有问题 | 当前规则 | 目的 |
|---|---|---|
| 相关词条不含所问属性时，仍可能只搜实体名 | 实体错误时修正实体；属性缺失时保留实体并补属性、年份、版本及同义关键词 | 第二轮针对证据缺口，减少重复读取概述 |
| 电影“演员”与“英文配音演员”等关系容易混淆 | 原始实体加具体属性，核对原版/配音版、获奖/提名、主持/主讲等关系 | 避免用相关但不回答问题的材料作证 |
| 年份和姓名同时出现在页面就容易被当成答案 | 检查标题、表头、行及年份与人物的明确关系 | 避免串年份、串类别 |
| 查询可能预先带上猜测答案 | 不以猜测人物或候选答案构造查询；确有材料支持的别名可用于修正实体 | 减少搜索对猜测的强化 |
| 要求补全姓名、解释机制及历史，可能引入额外错误 | 首句直接回答，通常 1～3 句；全名及别名须有依据，不编造中间名 | 保留准确事实，减少无依据扩写 |
| 搜索无证据后仍可能列出记忆中的演员、人物或数字 | 明确未核实之处，不枚举不确定候选；可靠背景须与检索结论区分 | 降低编造风险 |
| 英文题可能受中文工具观察影响 | 始终使用原始问题语言；工具观察不是新问题 | 保持回答语言一致 |
| 旧 Few-shot 的相对日期示例没有调用时钟 | 换成固定年份与具体关系的二次检索示例，以及同名药品不能证明批准的拒答示例 | 使示范与实际工具预算、来源规则一致 |

V3 从 5,814 字符降至 4,916 字符，减少约 15.4%；V2 从 3,360 增至 3,762 字符，以容纳明确的检索协议。字符数不是 Token 数，真实 Token 用量仍需逐次 usage 统计。

## 修改与验证边界

- 修改 `scripts/prompt_versions.py` 的 V2/V3，并同步核心文件的 V2 注释和 V3 默认提示词。
- V1、其他核心函数和配置、检索辅助层、两次搜索上限、课程评分和样本保持不变。已通过 AST、源码指纹和提示词相等检查。
- 健康科普身份、个人诊断与用药剂量边界、系统时钟和天气工具规则继续保留。
- 新增 `tests/diagnose_prompt.py`，可用真实模型配合固定的模拟工具观察，检查属性补查、年份类别、无证据拒答及语言与停止行为。所有问题和材料均为虚构，不是网页检索事实，也不是课程成绩或手工演示证据。

## 存档与复现

本轮快照目录：`outputs/prompt_versions/search_precision_20261015_102823_298380/`。

- `before/`、`after/`：修改前后核心文件与提示词副本。
- `manifest.json`：修改前及保持不变部分的来源指纹。
- `validation.json`：V1 未变、核心 AST 除提示词外未变、两处 V2/V3 同步，以及字符数变化。
- `diagnostic/interrupted.json`：首次模型请求长时间未返回后中断的记录，未取得回答及 usage。
- `diagnostic_bounded/results.json`：增加单请求 45 秒超时、关闭自动重试后的模型诊断状态。首项请求发生 `APITimeoutError`，后续 7 项标为 `not_run_after_error`，未取得可供对比的回答；不能将未运行项算作提示词失败，也不能据此评价改进效果。

本轮静态核对与语法检查通过，但真实模型诊断因接口超时未完成；没有新旧通过率可报告。诊断脚本保存每个已开始请求的状态、可用 usage、实际关键词及启发式检查，不输出密钥或异常请求内容。模拟材料诊断即使完成，也只检查有限的协议行为，不能证明真实网页搜索正确率。

如需复现诊断，应另选新输出目录，避免覆盖原记录。诊断会使用现有 `.env` 配置调用模型，但不会展示密钥，也不会执行网页检索：

```powershell
.\.venv\Scripts\python.exe -X utf8 tests/diagnose_prompt.py --baseline-dir outputs/prompt_versions/search_precision_20261015_102823_298380/before --output-dir outputs/diagnostics/prompt_check_new
```

本次根据 `exp_3` 的错误现象改写通用规则，没有将标准答案或补充评价别名注入提示词。针对固定集的调优过程应披露。尚未重新运行固定 30 题，之前 RAG 19/30 的成绩仅属于旧提示词；不能宣称本版已提高课程准确率。提示词也不能修复未被读取的网页表格、无关搜索结果或网络失败等检索层限制。

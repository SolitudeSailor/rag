# 实验指南

课程依据见[项目目标](../RAG项目目标.md)，安装与启动见[README](../README.md)，模块查询见[项目索引](../索引%20index.md)。本指南是操作说明，成绩与完成证据以实际对应目录为准。

## 第三部分：三版同题测试

准备至少四题：两道时效性／冷门事实题、一道常识题、一道已独立核验虚假前提的陷阱题。三版用相同文字与顺序，不向问题加入答案或纠正提示。

```powershell
.\scripts\run_project.ps1 -Task demo -Version V1
```

逐题输入，回答后手工截图，最后quit；以V2、V3重复。每题独立，无跨题记忆。盲答用`-Version blind`，不加“盲答”。环境演示至少RAG和盲答各一次，三版至少12项。单题可直接运行`.\.venv\Scripts\python.exe -X utf8 scripts\run_demo.py --version V3 --question "完整问题"`。

- 会话存于outputs/sessions/，每次启动一份、按首题命名、同名加序号；保存实际提示词、模型、回答、配置、来源尝试与状态。终端Token按本题全部调用累计。
- 用户截图存于outputs/screenshots/，包含版本、问题、真实关键词、Token和最终回答；长输出分图保留重叠，不展示密钥。
- 将[对比表模板](第三部分对比表模板.csv)复制到会话目录，按实际过程评价搜索、关键词、正确性、角色与编造情况，记录独立核验来源、截图和turn序号。
- 错误、拒答、空检索和失败均保留，不重问挑选答案。“不知道”不自动算正确；未完成的搜索指令不是答案。日志和模拟示例不替代手工截图。

## 提示词维护

V1保留教师版；V2/V3保持健康科普与医疗信息查询助手，不诊断、不推荐个人用药剂量。V3含1～2个完整模拟Few-shot及不确定时明确说明的规则，示例不作为真实检索证据。

V2/V3同步核心文件和scripts/prompt_versions.py；修改范围按[AGENTS.md](../AGENTS.md)及已有授权，保留搜索／回答标记和两轮上限。通过run_demo选择版本。

## 检索与实时工具

bing_search()委托scripts/search_sources.py执行：维基百科API正文优先，无有效词条时发现候选；无百科证据或涉及年份／时效词时补充Bing和实际权威引用网页。中文实体查中文版，其余查英文版。来源URL、修订及尝试记录随实际材料保存，百度百科旧版保留在outputs/retrieval_versions/。

时间指令为`搜索: 当前时间`，来自本机北京时间系统时钟。天气指令为`搜索: 天气 城市=北京 日期=明天`，通过Open-Meteo获取明确城市的近期模型资料或预报；歧义地点、远期日期、接口失败须说明，不能编造或称现场实测。完整参数、日期范围、表格与网页处理见[检索代码说明](检索代码说明.md)。

独立工具诊断不加载模型配置、不调用模型，保存于outputs/diagnostics/：

```powershell
.\.venv\Scripts\python.exe -X utf8 tests\diagnose_search.py --query '"photosynthesis" chloroplast'
.\.venv\Scripts\python.exe -X utf8 tests\diagnose_search.py --query '当前时间' --query '天气 城市=北京 日期=明天'
```

HTTP成功、摘要非空不证明答案正确。依次检查search_events[].source_attempts、selected_sources、实际材料和最终回答。会话及实验保存检索配置和源码哈希，检索修改另存版本。

## 第四部分：固定数据集实验

```powershell
.\scripts\run_project.ps1 -Task experiment -Workers 3
```

数据集缺失时下载指定NQ-open开发集3610题，seed=42固定抽样30题；每题盲答及V3 RAG，共60项，标准答案只用于评分。第三部分会话不参与统计。

统一入口创建outputs/experiment/exp_序号/，将本轮实际目录传给评测与导出，绘图使用.venv。仅重新统计时明确指定目录：

```powershell
.\scripts\run_project.ps1 -Task export -InputDir outputs\experiment\exp_1
```

export不调用模型；缺依赖时仍需联网安装。退出码0表示阶段成功，不代表准确率达标；2为有失败／未完成任务；1为环境、输入或子进程失败。

续跑只补缺失，已有失败不重试；显式运行`.\.venv\Scripts\python.exe -X utf8 scripts\evaluate.py --output-dir outputs\experiment\exp_1`。模型、接口、提示词、源码、检索配置、数据集或样本变化则停止。新实验用新目录。直接导出脚本默认取最新编号，最新未完成会报错，不回退旧成绩。

| 文件 | 内容 |
|---|---|
| sample30.json | 固定题目、原始索引、标准答案 |
| metadata.json、prompts.json | 实际配置、提示词与哈希 |

| results.csv、task_details.csv | 六列评分；任务状态、搜索数和累计Token |
| summary.json、accuracy.png | 汇总与准确率图 |
| token_comparison.csv、实验结果摘要.md | 前五题累计输入Token与摘要 |

## 评价规则

当前 V2/V3 检索协议已更新，改动与验证范围见[提示词优化记录](提示词优化记录.md)。修改后须重启问答；旧实验成绩不代表新提示词效果。

正式判分严格采用`any(ans.lower() in response.lower() for ans in answers)`，两模式一致，不做同义词、标点或词边界替换。包含标准答案即可能得分，同义表达未命中可能计错；人工核验可补充，不能替换课程评分。

现提供独立的[补充评价](补充评价说明.md)：核验过的别名、保守的边界匹配及人工复核。在项目根目录运行 `.\.venv\Scripts\python.exe -X utf8 scripts/supplementary_evaluation.py --input-dir outputs/experiment/exp_3`；结果另存，不改课程成绩。规则匹配不等于事实正确，未完成复核不报告语义准确率。

异常和未完成搜索计错、保留在30题分母；缺少任务拒绝统计。results.csv恰好六列：question、gold_answers、blind_answer、rag_answer、blind_correct、rag_correct。

准确率为正确题数/30×100%，增益为同轮RAG减盲答的百分点差。多对2题满足≥5，多对3题满足≥10的准确率条件；优秀还需图表与分析。固定集调优须报告全部轮次，不称独立泛化测试，不跨轮拼接、删除失败或挑选答案。

Token按每题所有调用累计，任何一次usage缺失则标未知；不以部分或最后一次用量充当完整值。选至少五题比较输入Token，结合调用次数、材料长度及真实效果写2～3句分析。

```powershell
.\scripts\run_project.ps1 -Task test
```

交付前检查要求覆盖、公式、表格、图片与分页；tools/render_word_pages.ps1仅检查已有Word，需要本机Word。

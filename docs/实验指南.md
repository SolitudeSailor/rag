# 实验指南

本项目历史生成数据曾清理，实际材料以现存对应实验目录为准，不混用不同轮次成绩。本指南是操作说明，不是完成证据。环境配置及统一入口见根目录README，任务与评分依据见《RAG项目目标.md》。

先运行`.\scripts\run_project.ps1 -Task setup`检查环境。启动器复用`.venv`，缺失时才创建；按`requirements.txt`补齐缺失依赖（包含Pillow），并验证导入及`pip check`。默认清华镜像，可通过`-IndexUrl`覆盖。所有模式使用项目Python，不依赖全局Python的包。安装或检查失败会停止；已有虚拟环境不会自动重建。

## 第三部分：三版同题测试

准备至少四个真实问题：两道时效性/冷门事实题、一道常识题、一道已独立核验虚假前提的陷阱题。V1/V2/V3使用完全相同的问题与顺序，不把答案或纠正提示加入问题。

```powershell
.\scripts\run_project.ps1 -Task demo -Version V1
```

逐题输入，回答完成后手工截图，最后输入quit。分别以V2、V3重复。默认每题独立作答，没有跨题记忆；直接调用run_demo.py的`--question "完整问题"`可只运行一题。统一入口的盲答演示使用`-Version blind`，无需给问题加“盲答”。环境跑通需RAG和盲答各至少一次真实演示；三版对比至少12个任务。

- 会话JSON存于`outputs/sessions/`，每次启动一份，以首题命名，同名加序号；包含提示词、实际回答、逐次搜索、usage和失败状态。
- 截图由用户手工保存至`outputs/screenshots/`，展示版本、问题、真实搜索关键词、Token和最终回答；长输出分图并保留重叠，不展示密钥。
- 将`docs/第三部分对比表模板.csv`复制到会话目录后，按实际过程填写。事实核验、关键词合理性、角色风格及是否编造分别判断；日志或模拟示例不能代替截图。
- 保留错误、拒答、空检索及失败，不重问挑选好答案。“不知道”不自动算事实题正确；未完成的“搜索:”不能当作最终答案。

## 提示词维护

V1保留教师基础版；V2/V3保持健康科普与医疗信息查询助手身份，不诊断、不推荐个人用药剂量。V3包含1～2个完整模拟Few-shot和不确定时的拒答边界，模拟示例不作为真实检索证据。

当前核心只允许修改V2/V3提示词，并同步`scripts/prompt_versions.py`；其他修改范围以AGENTS.md及用户明确授权为准。保留解析标记“搜索:”和“回答:”。用run_demo选择版本即可，无需更改核心函数。

## 第四部分：固定数据集实验

```powershell
.\scripts\run_project.ps1 -Task experiment -Workers 3
```

统一入口先创建本轮编号目录，再执行评测和对应目录的导出；绘图也使用项目`.venv`。仅重新绘图与统计时使用：

```powershell
.\scripts\run_project.ps1 -Task export -InputDir outputs\experiment\exp_1
```

export必须指定实际实验目录，不调用模型，不自动选择其他轮次。依赖缺失时仍需联网安装。退出码0表示阶段成功，不代表准确率达标；2表示已导出但有失败/未完成任务；1表示环境、输入或子进程失败。

数据集缺失时自动下载指定NQ-open开发集3610题，使用seed=42固定抽样30题。每题分别执行盲答和V3 RAG，共60项；标准答案只用于评分，不传模型。第三部分会话不参与本部分统计。

每次启动评测自动新建`outputs/experiment/exp_1`、`exp_2`等下一编号目录；本轮题目、回答、搜索日志、Token和图表均保存到对应目录。默认导出统计最新编号；最新实验未完成则报错，不回退挑选旧结果。续跑需显式指定`--output-dir outputs/experiment/exp_1`，导出指定某轮使用`--input-dir outputs/experiment/exp_1`。同配置续跑仅补缺失任务，已有失败不自动重试。模型、接口、提示词、源码、数据集或样本变化时停止续跑；新实验使用新目录，不覆盖此前结果。

| 文件 | 用途 |
|---|---|
| sample30.json | 固定30题、原始索引和标准答案 |
| metadata.json、prompts.json | 配置、实际提示词及哈希 |
| raw_results.json、search_traces/ | 完整答案、搜索、状态和逐次usage |
| results.csv | 正式六列评分明细 |
| task_details.csv | 状态、搜索数和累计Token |
| summary.json、accuracy.png | 汇总及准确率柱状图 |
| token_comparison.csv、实验结果摘要.md | 前五题输入Token及摘要 |

## 统一评价标准

正式判分采用课程原式：`any(ans.lower() in response.lower() for ans in answers)`。盲答与RAG使用同一标准，不做同义词、标点或词边界替换。多候选提及标准答案也会判对；同义表述未命中也会判错，这是字符串评分的局限。

异常及未完成搜索不算最终回答，计错并保留在30题分母；缺失任务拒绝统计。`results.csv`恰好六列：question、gold_answers、blind_answer、rag_answer、blind_correct、rag_correct。

准确率为正确题数/30×100%；增益为同轮RAG减盲答的百分点差。多对2题满足≥5个百分点，多对3题满足≥10个百分点的准确率条件；优秀还需规范图表和结果分析。不跨轮拼接盲答，不删除失败题、不挑选逐题答案。固定集调优须完整报告轮次，不能称独立泛化测试。

Token按每题全部调用累计；有一次usage缺失则累计标为未知，不将部分用量当完整用量。分析写2～3句，结合调用次数、摘要长度及真实结果。人工事实核验可另作补充，不替换课程评分。

评分实现集中于`scripts/experiment_utils.py`，评测和导出共用。测试与诊断放在`tests/`。运行全部离线测试：

```powershell
.\scripts\run_project.ps1 -Task test
```

## 诊断与报告

搜索可返回非空但无关的摘要，HTTP成功不等于事实已核验。用`tests/diagnose_search.py --help`查看只读诊断参数；模型未取得相关证据时，应如实记录，不能称联网确认。修改核心检索前遵循授权范围。

报告另存可编辑Word至`reports/`，暂不生成PDF。保留“一”至“七”的章节和原小题名称，封面与真实分工置于正文前；理论12小题各100～200字，公式规范；包含准确率图、至少五题Token对比及分析。三人姓名学号、真实分工和每人不少于200字的本人总结由用户补齐，不代编经历。交付前检查要求覆盖、公式、表格、图片清晰度与分页；`tools/render_word_pages.ps1`用于已有Word的分页检查。

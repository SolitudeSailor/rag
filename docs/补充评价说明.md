# 补充评价说明

课程正式成绩仍按任务书规定的字符串包含规则计算。新增 `scripts/supplementary_evaluation.py`，用于离线识别已核验替代表述，并组织人工复核；不修改模型回答、标准答案、正式六列 CSV、原有分数或准确率图。

## 改进规则

1. 对大小写、全半角、空白、部分引号和 Markdown 标记进行归一化，不随意删除姓名的中间词。
2. 英文和数字使用词边界，防止 `7` 匹配 `1979`、`Rice` 匹配 `price`。
3. 接受经过核验的替代表述，配置保存于 `data/evaluation_aliases.json`。每条必须包含问题、标准答案、替代表述、核验日期、理由和证据链接；仅用于相应问题，不自动推断任意省略中间名的姓名等价。
4. 检出否定、不确定或候选表达，仅在后续解释中出现答案，或涉及数字、日期、范围和单位时，转人工复核。
5. 未匹配的回答进入待复核，不直接判错。失败或没有最终回答仍计错、保留在 30 题分母。

自动结果分为 `matched`（规则匹配，仍待人工确认）、`needs_review`（待复核）、`incorrect`（运行失败或空回答）。这些规则只能发现部分语义风险，无法保证识别所有否定、矛盾或候选名单，也不判断回答的全部附加信息是否正确，因此不将自动匹配率标成语义准确率。中文同义表达、跨语言答案和未收录别名应复核后再决定是否加入规则。

## 当前已核验的例子

本轮第 16 题询问《Let's Make a Deal》的模特。标准答案为 `Tiffany Adams Coyne`，[CBS 官方人物页](https://www.cbs.com/shows/lets_make_a_deal/cast/67164/)及[本人官网](https://tiffanycoyne.com/)均使用 `Tiffany Coyne` 并说明节目模特身份，因此接受该写法作为本题替代答案。不是仅凭两个姓名相似就认定等价。

`exp_3` 中盲答和 RAG 均使用 `Tiffany Coyne`，原规则均判错；新别名规则应对两模式同时生效。本例不会单独扩大 RAG 相对盲答的优势。

这项规则是在查看固定 30 题结果后新增的，属于事后补充分析，不能称为独立泛化测试。新增别名必须有证据，不能为提高某一模式成绩而只检查该模式的错误题，也不能将评价用别名或标准答案注入生成、检索提示词。

## 运行与人工复核

使用现有 `.venv`，仅用 Python 标准库，不联网、不加载 `.env`、不调用模型：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/supplementary_evaluation.py --input-dir outputs/experiment/exp_3
```

结果另存于指定实验的 `supplementary_evaluation/review_序号/`，每次新建目录：

- `details.csv`：60 项任务的原始回答、课程判分、补充结果、理由和证据。
- `manual_review.csv`：所有正常任务的人工复核表，包含自动匹配项，防止只复核未命中的答案。
- `summary.json`、`说明.md`：分别统计盲答与 RAG 的规则匹配、待复核、人工判对和判错数。
- `aliases.json`、`supplementary_evaluation.py`：本次规则快照；摘要记录输入数据与代码 SHA-256。

用户核验时填写 `manual_review.csv` 的 `decision`（`correct` 或 `incorrect`）、`reviewer`、`reason`、`evidence`，保持 `task` 和 `record_sha256` 不变。核验理由应说明实体是否相同、答案是否明确以及题目时间语境；可引用官方网页或原始检索证据。不能只因包含某个名字就勾选正确。

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/supplementary_evaluation.py --input-dir outputs/experiment/exp_3 --reviews outputs/experiment/exp_3/supplementary_evaluation/review_1/manual_review.csv
```

只导入填写了结论的行，未填行保留原状态。导入前校验任务与问题、标准答案、模式、状态、回答的指纹，拒绝错配、重复、无理由和无证据的记录。所有正常任务均完成人工复核后，才计算该模式的最终补充准确率；在此之前为 `null`。人工判分与课程成绩并列展示，不覆盖课程评分。

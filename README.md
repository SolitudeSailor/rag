|需要做什么|在VS Code中打开并运行|

|自动完成30题、盲答和V3 RAG两模式共60项|**[run_30.py](run_30.py)**，点击右上角运行，无需输入指令|

## 环境配置

从GitHub下载并完整解压后，先双击根目录的 **[一键配置环境.cmd](一键配置环境.cmd)**。它会检测已有Python 3，创建或复用项目`.venv`，自动补齐pip和缺失依赖，并运行依赖兼容性检查；窗口会保留成功或失败提示，完成后再运行`run_30.py`。此双击入口使用Windows自带命令处理器，无需额外安装PowerShell。安装依赖需要联网，电脑需已安装Python 3。

项目环境与全局Python隔离，可避免全局环境中`humanfriendly`缺少`pyreadline3`等无关依赖导致启动检查失败。已有`.venv`损坏或依赖冲突时会报错并停止，不覆盖环境。此步骤仅准备环境，不运行测评或验证模型服务是否可用。

复用已有`.env`和`.venv`。首次配置参照`.env.example`设置`LLM_API_KEY`、`LLM_API_BASE`、`LLM_MODEL`，不输出或提交密钥；额外参数通过`LLM_EXTRA_BODY` JSON传递。服务商自带联网必须关闭，已识别的通义千问和智谱官方接口有关闭设置，其他服务须在实际服务端核实。

需要准备环境或检查代码时，在根目录使用PowerShell 7：

```powershell
.\scripts\run_project.ps1 -Task setup
.\scripts\run_project.ps1 -Task test
```

启动器只补缺失依赖，不重复安装。执行策略阻止时，在命令前使用`pwsh -NoProfile -ExecutionPolicy Bypass -File`。依赖为OpenAI兼容客户端、requests、BeautifulSoup、dotenv与Pillow，绘图采用基础路径。

## 第三部分 手工对照

```powershell
.\scripts\run_project.ps1 -Task demo -Version V3
.\scripts\run_project.ps1 -Task demo -Version blind
.\scripts\run_project.ps1 -Task demo -Version blind -TimeInjection off
.\scripts\run_project.ps1 -Task demo -Version blind -TimeInjection on
```

先完成两模式各一次真实问答；时间注入前后均问“今天日期是？”，截图并用2～3句分析实际差异，不预设模型一定答错。再分别以`-Version V1`、`V2`、`V3`测试同四题：至少两道时效性或冷门题、一道常识题、一道已核验陷阱题。记录搜索行为、关键词合理性、答案正确性、角色风格、是否编造及核验依据，每版保留完整截图。

会话自动存入`outputs/sessions/`，手工提问、事实核验与截图由组员完成。V1保留教师原文；V3有拒答规则及两个明确标为虚构的完整Few-shot，模拟内容不算真实证据。时间注入只提供北京时间，不能代替实时天气或汇率。

## 第四部分 评测与离线导出

日常直接运行`run_30.py`。需要调整并发或重新导出已有轮次时：

```powershell
.\scripts\run_project.ps1 -Task experiment -Workers 3
.\scripts\run_project.ps1 -Task export -InputDir outputs\experiment\exp_5
```

export只核验指定轮次并重建统计、图表和Token表，不调用模型、不重新获取标准值。八列`results.csv`、`accuracy.png`、`token_comparison.csv`和`实验结果摘要.md`用于报告，完整文件含义见[项目结构.md](项目结构.md#每轮实验的产物)。摘要中`auto-statistics`标记内由程序更新，人工分析写在标记外，重导出会保留。

评测约束：

- 教师固定15天气＋15汇率全覆盖，每题现场取得标准值，两模式共享；标准值只用于评分，不进入模型上下文或检索材料。盲答与V3 RAG均注入北京时间。
- 评分沿用教师函数：天气±3℃、汇率±1.5%。标准值缺失不计分并报告有效分母；其他失败计错，全部记录保留，不跨轮拼接或只重跑错题替换答案。
- 保留ReAct和两轮搜索上限。天气首轮“城市天气”，证据不足时第二轮精确实体加引号并设置中文地区参数；每轮最多补读一个实际Bing结果中的天气网城市首页，核对城市、当天日期和当前温度栏，不用预报替代。页面日期、抓取时间不充当观测时刻。
- 汇率首轮“中国银行外汇牌价 币种名”，不足时第二轮将来源与币种分别加引号。只读实际结果中的中行官网当日目标行，核实100外币单位，固定以现汇买卖价均值/100计算参考值并披露口径、发布时间和来源。缺少有效证据可拒答，不根据标准值选择价格列。
- 同URL连接、超时、429或5xx故障最多请求两次，逐次记录参数和状态，不关闭TLS校验或增加隐藏搜索。模型单次请求超时60秒，SDK隐式重试关闭，外层最多尝试两次；任次usage缺失则完整累计Token未知。
- 导出核对固定题目、源码指纹、实际提示词、原始回答、教师判分和Token累计。指纹只证明档案内部一致性，不能证明服务商内部未联网。

退出码0表示流程完成，不保证准确率达标；1表示环境或文件失败；2表示已导出但有标准值缺失或失败任务；130表示中断。90%目标要求标准值30/30完整且RAG至少答对27题，独立于课程“提升5或10个百分点”的达标线。
